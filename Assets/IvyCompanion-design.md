# Ivy pixel companion

Source sheet: `Sources/Ivy/Resources/IvyCompanionSprites.png` (1254 × 1254 RGBA; 4 × 4 grid).
Generated using the built-in imagegen tool with the user-supplied image as a style reference. The original transparent sheet is packaged unchanged. Swift extracts and caches each equal grid cell without smoothing.

## Prompt

Use case: stylized-concept. Asset type: a production sprite sheet for an animated desktop companion named Ivy. The attached pink-haired pixel character is ONLY a reference for its very chunky low-resolution pixel art style and tiny full-body chibi proportions, not its identity or colors. Create Ivy herself: dark espresso long wavy hair with one small green ivy-leaf hair clip, violet eyes, charcoal oversized sweater, dark trousers and short boots, confident dry-witted expression. Wholesome little software assistant, smart and slightly sarcastic, never romantic or flirty. Authentic chunky pixel art, obvious large square pixels, limited palette, clear readable facial expressions, no smooth vector outlines, no airbrush, no neon, no text. Transparent background. Square sprite sheet containing EXACTLY 16 full-body sprites in an EXACT uniform 4-column by 4-row grid. Invisible grid: no lines, dividers, panels or labels. Keep EVERY sprite entirely inside its own equal square cell, with identical character scale and foot baseline, generous transparent margins, no overlap. Each sprite is centered horizontally. Consistent identity, outfit, proportions and dark plum outline in every cell. Read cells left-to-right, then top-to-bottom. Row 1: idle relaxed smirk eyes open; same idle pose blinking eyes closed; listening attentively with hand near ear eyes open; same listening pose slight head tilt. Row 2: thinking hand on chin with skeptical side-eye; same thinking pose eyes glance the other way; speaking with one hand gesturing mouth closed; same speaking gesture mouth open. Row 3: working focused holding a small neutral tablet at waist; same working pose tapping tablet; awaiting approval arms crossed raised eyebrow; same awaiting approval pose blinking. Row 4: error wry shrug palms up; same shrug slightly lowered hands and resigned expression; greeting waving right hand outward; same greeting hand tilted inward. Full character head-to-boots visible in ALL 16 cells. Each figure is about 75 percent of the cell height, so all expressions and hands fit with transparent clearance. Deliver only the transparent sprite sheet.

## Playback

Frame pairs: idle 0–1, listening 2–3, thinking 4–5, speaking 6–7, working 8–9, approval 10–11, error 12–13, greeting 14–15. Speaking follows measured output audio; progress follows actual task completion. Reduce Motion freezes the base pose and removes translation and scaling. Hidden panels pause their timeline. The main app keeps its neutral professional appearance.
